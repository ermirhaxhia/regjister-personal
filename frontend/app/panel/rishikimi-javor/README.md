# Rishikimi Javor

Qëllimi: faqja "Java në numra" — katër metrika krahasuese javë-me-javë
(shpenzime, gjumë mesatar, përqindje zakonesh, hapa/ditë) plus tri fusha
reflektimi me ruajtje automatike.

Përmban: `page.tsx` — navigim javë-mbrapa/javë-para, pllaka metrikash,
formë reflektimi.

Lidhet me: `lib/api.ts` (`getWeeklySummary`, `getWeeklyReview`,
`upsertWeeklyReview`), `lib/date.ts` (`weekRangeLabel`, `durationLabel`,
`addDays`), `components/rishikimi-javor/`.
